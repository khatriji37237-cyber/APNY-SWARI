# APNY-SWARI
ApnySwari ek modern, dynamic, aur lightweight ride-booking platform hai jo aapko bike, auto, aur cab ki suvidha ek hi jagah par pradan karta hai. Yeh app khas taur par un users ke liye design kiya gaya hai jo apne shehar mein aasaani se safar karna chahte hain aur bina kisi jhanjhat ke turant fair (kiraya) calculate karke ride book kar sakte hain.
